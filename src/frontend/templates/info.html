Handling real-world requests

Not every request is clear-cut — AgentCare treats that as normal, not an error.

Clear request

"Book me a cardiology appointment for next Tuesday morning and remind me a day before."

Straight through. Department, action, and timing are all present, so the request is routed, booked, and a reminder is scheduled in one pass — no back-and-forth.

Ambiguous request

"I need to see a doctor."

Asks, doesn't guess. With no department or intent to go on, the system pauses and asks one clarifying question — the same way a good intake coordinator would — then continues from the patient's answer instead of misrouting the request.

Potential emergency

"I have severe chest pain and can't breathe."

Immediate human escalation. This is caught by a fixed, code-level rule before any AI reasoning even runs, and goes straight to the staff console for review — it can never get "argued out of" escalating.

Agent architecture

Six distinct agents, each with its own prompt, tools, and job.

Coordinator Agent

Understands the goal, decides which specialist agents to run, and merges their outputs into one confirmation.

{{ icons.shield("icon") }}

Safety & Escalation Agent

Blocks diagnosis/prescription requests and emergencies in code, and creates human-review escalations.

{{ icons.route("icon") }}

Department Routing Agent

Understands the request and picks the matching department from the hospital's real, active list — its choice is always checked against real records, so it can never route to a department that doesn't exist.

{{ icons.calendar("icon") }}

Appointment Agent

Checks live slot availability and conflicts, then books, reschedules, or cancels against persisted data.

{{ icons.file_text("icon") }}

Document Agent

Classifies uploads, detects duplicates by checksum, and flags missing documents per department.

{{ icons.bell("icon") }}

Follow-up Agent

Creates appointment and document reminders, and hands off to the notification dispatcher.

AgentCare is an administrative coordination system, not a clinical one.

It never diagnoses conditions, prescribes medication, or recommends dosages. Emergencies and clinical questions are always escalated to a human. This boundary is enforced in the Safety & Escalation Agent's code, not just its prompt.
